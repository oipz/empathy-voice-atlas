# 中文共情语音：数据集与测试集设计

面向端到端中文语音聊天系统。核心问题是：理解用户处境、回复内容共情，同时语音自然、好听、情感表达合适；不要求必须依赖输入声音中的隐含线索。

## 明天先看这些

1. 打开 [网页](dist/index.html)：45个相关数据集/基准的中文介绍，可筛选搜索，含官方来源、数据结构概述、测试方式、获取限制及自编示意。
2. 阅读 [完整方案](docs/方案.md)：主轨道240情境，另设可选声音线索与固定文本情感控制诊断，分别评分。
3. 浏览 [24个原创文字样例](docs/pilot_24.jsonl) 或 [一个完整样例](docs/example_complete.json)。它们尚未录音、未人工验证，不是已经完成的音频测试集。
4. 使用 [评分表](docs/ratings_template.csv)、[输出模板](docs/output_template.json) 和 [字段定义](docs/schema.json) 准备小规模预试。

网页支持直接打开本地HTML，不需要构建或安装依赖。也可以在仓库目录运行 `python -m http.server 8767 --directory dist`，访问 `http://localhost:8767`。

## 核心建议

- 首先看 HumDial-EIBench 中文Task 3 的端到端共情生成；它将文本共情、声音共情、音质自然度分开。
- 中文内容借鉴 CPED、PsyQA、SoulChat，但要人工筛选改写，避免把电视剧回应或合成咨询文本当金标准。
- 输出情感表达参考 ESD、CSEMOTIONS；上下文表达适切性参考 CEAEval-D；自然度另参考 ATT。
- 用户生气不意味着助手也必须生气。主测试允许多种适切语气；只有明确指定情感的控制轨道才计算情感类别准确率。

## 范围与状态

资料核查日期：2026-11-16。45项是代表性相关资源及此前讨论基准，不是全球所有数据集的穷尽目录。每项官方入口和获取限制见 [机器可读目录](docs/catalog.json)。目录中的条目数量不是新下载的数据集数量。

本仓库包含自编介绍、网站与测试设计。没有打包第三方完整数据、未授权音频、凭据、模型输出成绩或真人录音。此前EchoMind与URO中文Basic的下载文件仍在本地，不包含在这个轻量仓库内；网页保留此前浏览站链接。

ESD等数据需作者许可；PsyQA完整数据需签署协议申请。代码仓库许可不自动覆盖第三方数据；请分别核对数据、模型和代码条款。所有卡片任务例子和24题都是原创示意，不是对原论文样本的摘录。

`docs/` 和网页 `dist/files/` 是同一组下载文件；`tools/build_atlas.py` 保留内容构建脚本，可从原始工作区重新生成目录和样例。
